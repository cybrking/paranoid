# UI-88: Show amounts in the customer's currency format

The invoice table shows raw cents. Format them for display:

| cents | currency | shows |
|---|---|---|
| 123450 | USD | $1,234.50 |
| 123450 | EUR | 1.234,50 € |
| 5 | USD | $0.05 |
| -2500 | USD | -$25.00 |

Implement `format_money(cents, currency)` in `app/money.py`. Only USD and EUR for now.
